# RAI1903

Plataforma frontend no oficial sobre el Real Avilés Industrial, construida con Next.js App Router, TypeScript y Tailwind CSS.

## Scripts

- `npm run dev`: arranca el entorno local.
- `npm run build`: compila la aplicacion para produccion.
- `npm run lint`: ejecuta ESLint.
- `npm run typecheck`: valida TypeScript sin emitir archivos.

Los datos mock viven en `/data` y estan tipados en `/types`, preparados para sustituirse mas adelante por Supabase, API propia o base de datos.
